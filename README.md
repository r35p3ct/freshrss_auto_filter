# FreshRSS AutoFilter

Расширение для FreshRSS, которое автоматически определяет рекламные записи в RSS-лентах с помощью AI (OpenRouter API) и помечает их метками.

## Как работает

При получении новой записи из RSS расширение отправляет заголовок и содержимое в OpenRouter. AI возвращает JSON-оценку: является ли запись рекламой и с какой уверенностью.

### Режимы работы

| Режим | Что происходит | Когда использовать |
|-------|---------------|-------------------|
| **Синхронный** | Запись проверяется сразу при добавлении, AI-запрос блокирует обновление ленты | Простые установки без API-клиентов |
| **Фоновый** *(рекомендуется)* | Запись сразу добавляется с меткой `Непроверено`, а скрипт по cron постепенно проверяет их через AI | Если используете CapyReader, Fluent Reader или другие клиенты — убирает задержки при обновлении |

### Метки

- `Реклама` — уверенность > 80%. Запись помечается прочитанной.
- `Подозрение` — уверенность > 50%.
- `Непроверено` — ждёт проверки в фоновом режиме.
- `Проверено` — проверена вручную.

## Установка

1. Скопируйте папку `xExtension-AutoFilter` в `freshrss/extensions/`.
2. В FreshRSS перейдите в **Настройки → Расширения** и включите **AutoFilter**.
3. Создайте 3 метки в **Управление метками**:
   - `Реклама`
   - `Подозрение`
   - `Непроверено`
4. Откройте настройки расширения, вставьте **API-ключ** с [openrouter.ai/keys](https://openrouter.ai/keys) и сохраните.

## Настройка фонового режима (рекомендуется)

1. В настройках расширения поставьте галочку **"Фоновый режим"**.
2. Настройте **размер пакета** (сколько записей проверять за раз, по умолчанию 5).
3. Настройте **задержку** между запросами (по умолчанию 2000 мс) — помогает избежать rate limit на бесплатных моделях.
4. Добавьте в cron:

```bash
*/5 * * * * docker exec freshrss php /var/www/FreshRSS/extensions/xExtension-AutoFilter/scripts/process_pending.php
```

При обновлении лент новые записи мгновенно появляются в клиенте с меткой `Непроверено`, а cron-скрипт постепенно проверяет их и заменяет метку на результат.

## Требования

- FreshRSS 1.20+
- PHP 7.4+
- API-ключ OpenRouter
